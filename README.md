# Processo estruturado de recrutamento e seleção

contratar com os mesmos critérios para todos os candidatos, de forma rápida e justa.

## O que tem aqui
- **Descrição de vaga** (`modelos/descricao-de-vaga.docx`): Modelo para definir cargo, requisitos e perfil antes de divulgar.
- **Roteiro de entrevista** (`modelos/roteiro-entrevista.docx`): Perguntas por competência, iguais para todos os candidatos.
- **Ficha de pontuação** (`modelos/ficha-pontuacao.xlsx`): Notas com pesos, total e ranking automáticos.
- **Acompanhamento de candidatos** (`modelos/acompanhamento-candidatos.xlsx`): Funil, tempo para contratar e custo por contratação.

## Como funciona
- **Etapas:** definir cargo e perfil, divulgar a vaga, triar currículos, fazer entrevista por competências com roteiro, pontuar cada candidato e dar retorno a todos.
- **Entregas:** modelo de descrição de vaga, roteiro de entrevista, ficha de pontuação e planilha de acompanhamento dos candidatos no Excel.
- **Indicadores:** tempo para preencher a vaga, custo por contratação e rotatividade nos primeiros 90 dias.
- **Base:** curso de Recrutamento e Seleção de Pessoas (Udemy).

## Como publicar na Vercel (sem programar)
1. No GitHub, crie um repositório novo e envie estes arquivos (botão **Add file → Upload files**).
2. Em [vercel.com](https://vercel.com), clique em **Add New → Project** e escolha este repositório.
3. Deixe tudo como está e clique em **Deploy**. Em alguns segundos o site estará no ar.

Para atualizar, troque os arquivos no GitHub e a Vercel publica de novo sozinha.
